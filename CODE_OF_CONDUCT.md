# Code of Conduct

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](CODE_OF_CONDUCT.vi.md)

We welcome respectful, constructive technical discussion and contributions from people with different backgrounds and experience levels.

## Expectations

- Give actionable feedback on code, tests and documentation.
- Debate decisions without personal attacks or harassment.
- Respect copyright, upstream license requirements and attribution.
- Protect credentials, private data and unreleased security findings.

Threats, discriminatory abuse, publishing another person's private information and deliberately disruptive behavior are not acceptable.

## Reporting and enforcement

Report concerns privately to **Đăng Khoa <i.am@dangkhoa.dev>**, with relevant context. Security vulnerabilities must follow [SECURITY.md](SECURITY.md). The maintainer may moderate or reject harmful discussions and contributions proportionately.

This applies to repository issues, pull requests and related project interactions.
