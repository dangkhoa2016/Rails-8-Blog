# Support

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](SUPPORT.vi.md)

Before reporting a problem, check the [quick start](docs/QUICKSTART.md), [architecture](docs/ARCHITECTURE.md) and [troubleshooting](docs/TROUBLESHOOTING.md).

For a reproducible issue, provide the exact source revision, environment, steps, expected and actual results, and sanitized logs. For feature requests, explain the use case and acceptance criteria.

Never post credentials, database dumps or private media. Follow [SECURITY.md](SECURITY.md) for vulnerabilities.

Community support has no guaranteed response time or managed hosting SLA.
