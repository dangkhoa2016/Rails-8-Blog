# Bundled Asset Rights and Provenance

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](ASSET_PROVENANCE.vi.md)

## Scope

Rails 8 Blog distributes a small set of image assets in the Git source. The project's [MIT license](../LICENSE) does **not** establish ownership of images obtained from others. This is a cautious inventory, **not** a claim that all rights have been independently verified.

## Project-authored account illustrations

All six illustrations—`confirmation.png`, `login.png`, `registration.png`, `forgot-password.png`, `profile.png`, and `unlock.png`—were generated specifically for this project as transparent PNG images without matching editable vector sources. Their illustrated content is proportionally framed for the shared Devise layout. Superseded SVG drawings that do not match the current PNGs are not distributed. The project does not knowingly incorporate third-party stock artwork into these illustrations.

The three favicon files remain unchanged. The maintainer will supply the provenance, applicable license and attribution obligations for those assets. A checksum or source-code license alone does not establish redistribution rights.

## Publication checklist

- [ ] Confirm the provenance and redistribution rights of the three retained favicon files.
- [ ] For externally sourced assets, retain creator, source URL, license identifier and attribution obligations.
- [ ] Replace or remove any asset without an appropriate right to redistribute.
- [ ] Record any fonts, icons, diagrams or bundled media added in future.
- [ ] Verify that users uploading their own content have permission to do so.

The retained favicon files require source and redistribution-rights confirmation before public reuse. See [Third-party Notices](../THIRD_PARTY_NOTICES.md).
